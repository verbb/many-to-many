Many To Many keeps a Craft relationship editable from either side. Connect related elements once, then let authors manage the association from whichever record they are already working on.

Configure the paired element field and let the plugin synchronise changes across both sides. Authors can connect or remove related content from the place that makes sense without leaving conflicting relationship data behind.

## Features

- **Two-way editing:** Add or remove a relationship from either participating element.
- **Synchronised values:** Update the paired field when one side of the relationship changes.
- **Craft field workflow:** Use familiar element-selection controls in the authoring interface.
- **Native relations:** Query related Craft elements with established template patterns.
- **GraphQL:** Query the paired relationships in headless implementations.
- **Paired fields:** Define which field represents the reverse side of the association.
- **Less author friction:** Edit the connection without navigating to a particular “owning” record.
- **Native Craft relations:** The field uses Craft’s element-selection patterns and stores real element relationships, so templates and queries can work with the selected elements in the usual way.

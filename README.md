<h1 align="center">Many to Many for Craft CMS</h1>

Many to Many is a Craft CMS plugin that keeps element relationships editable from either side. Connect related content once, then let authors manage the association from whichever element they are already working on.

Configure a paired Craft relation field and Many to Many field. When an author changes either side, the plugin updates the same underlying Craft relation on the linked elements.

## Features

- Add or remove relationships from either participating element.
- Connect entries, categories, users and assets.
- Keep the paired Craft relation field in sync when the reverse field changes.
- Use Craft’s familiar element-selection controls.
- Access related elements directly in Twig or with `relatedTo()` queries.
- Eager-load relationships and query them through GraphQL.
- Restrict linked content to a section, category group, user group or asset volume.
